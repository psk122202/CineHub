# CineHub — библиотека фильмов и сериалов для Android TV

Kotlin + Jetpack Compose for TV + Media3 (ExoPlayer).

## Что умеет

- **Каталог TMDB**: тренды, популярное, лучшее, «сейчас в кино», жанры, поиск, описание, актёры, сезоны и серии, похожие, трейлеры (YouTube).
- **«Где смотреть»**: легальные сервисы для вашей страны (Netflix, Megogo, Sweet.tv, Disney+ и др.) — по нажатию открывается приложение сервиса на ТВ.
- **Свои источники** с воспроизведением прямо в приложении:
  - Jellyfin / Emby (логин и пароль), Plex (адрес + X-Plex-Token) — с синхронизацией просмотренного;
  - сетевые папки SMB (Windows, NAS);
  - видео на самом ТВ и флешках;
  - плейлисты M3U (с группами, логотипами, User-Agent/Referer);
  - прямые ссылки на видео (mp4, mkv, m3u8/HLS, mpd/DASH).
- **Единый поиск** сразу по TMDB и всем источникам; на карточке фильма из TMDB приложение само ищет его в ваших источниках.
- **Плеер**: продолжение с места остановки, автопереход к следующей серии, выбор дорожек и субтитров, предпочтение языка.
- **Профили** (у каждого своё избранное, «Буду смотреть», история и «Продолжить просмотр»).

## Как получить APK (без Android Studio)

1. Создайте бесплатный аккаунт на github.com → **New repository** (можно Private).
2. Загрузите в него все файлы этой папки (кнопка **Add file → Upload files**, перетащите содержимое папки, включая скрытую папку `.github`).
   - Если папка `.github` не загрузилась: в репозитории **Add file → Create new file**, имя `.github/workflows/build.yml`, вставьте содержимое файла из архива.
3. Откройте вкладку **Actions** — сборка запустится сама (около 5–8 минут).
4. Когда появится зелёная галочка — откройте сборку, внизу в **Artifacts** скачайте `CineHub-apk` (внутри `CineHub.apk`).
5. (Необязательно) Чтобы ключ TMDB был вшит в APK: **Settings → Secrets and variables → Actions → New secret**, имя `TMDB_API_KEY`. Иначе просто введите ключ в Настройках приложения.

## Установка на телевизор

- **Флешка**: скопируйте APK на флешку → на ТВ откройте файловый менеджер (например, «File Commander» или «X-plore») → установите. Разрешите «установку из неизвестных источников» для файлового менеджера.
- **Без флешки**: установите на ТВ приложение «Downloader» (AFTVnews) или «Send Files to TV» и передайте APK с телефона/компьютера.

Все сборки подписаны одним ключом (`app/app-signing.jks`), поэтому новые версии ставятся поверх старых без потери данных.

## Первый запуск

1. **Настройки → Каталог TMDB**: вставьте бесплатный ключ с themoviedb.org (Настройки профиля → API).
2. **Источники → Добавить**: ваш Jellyfin/Plex/сетевую папку/плейлист.
3. Удерживайте **ОК** на любой карточке — она добавится в избранное.

## Сборка в Android Studio

Откройте папку проекта → дождитесь Gradle Sync → **Run** на эмуляторе Android TV или телевизоре (по ADB). Ключ TMDB можно вписать в `gradle.properties`.

## Структура

```
app/src/main/java/com/cinehub/tv/
  model/Media.kt            единая модель элемента для всех источников
  data/Repository.kt        AppContainer: профили, избранное, прогресс, источники, поиск
  data/tmdb/Tmdb.kt         каталог TMDB
  data/sources/*            Jellyfin, Plex, SMB, M3U, локальные файлы, ссылки
  player/                   плеер Media3, SMB-стриминг, очередь
  ui/                       тема, меню, навигация, компоненты
  ui/screens/*              экраны
```

Чтобы добавить новый источник — реализуйте интерфейс `VideoSource` (`data/sources/Source.kt`) и зарегистрируйте его в `AppContainer.build()`.

Названия пакетов стриминговых приложений для кнопок «Где смотреть» — в `ui/External.kt`, их можно дополнять.

## Ограничения

- Звук DTS/TrueHD и некоторые кодеки зависят от возможностей конкретного телевизора.
- Plex-токен вводится вручную (вход через plex.tv не реализован).
- Синхронизации между устройствами нет — используйте Jellyfin/Plex как общий «центр»: прогресс там сохраняется.

Этот продукт использует TMDB API, но не одобрен и не сертифицирован TMDB.
